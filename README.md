# Chaarkone — Demo Website

Storytelling-first, product-focused demo redesign of chaarkone.com, built for internal review (Haider).

- Concept: "the site is a loom" — Chaarkone means *four corners*; every screen is worked inward from four corners, with a scroll-driven signature section where four corner pieces close in over a rug until they meet.
- Story: founder Haider Quasim Raza's origin ("Why should anyone have to compromise when it comes to their home?"), designed in Lucknow, crafted in Bhadohi.
- Products: real Chaarkone designs (Floral AATC-912/928/929/947, Magnolia AATC-320 in 4 colourways, Fine Magnolia AATC-615, Retro AATC-602, AZ-2015, AZ-2025) with real photography from chaarkone.com, filterable shop, colourway switcher, live per-sq-ft pricing (INR/USD/CAD), wall art, craft, process, bespoke + free swatches, cart/demo checkout.
- Lucknowi layer: Nawabi maroon + brass, Awadhi arch frames, jaali lattice dividers.

`index.html` is a single self-contained file (assets inlined). Prices shown are illustrative demo rates, not final rates. The live chaarkone.com is untouched.
